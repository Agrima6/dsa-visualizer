# Binary Tree

A binary tree is a hierarchical data structure composed of nodes, where each node contains a value and can have up to two children: a left child and a right child.

## Properties
- Each node has at most two children
- The left child is typically smaller than the parent
- The right child is typically larger than the parent

## Common Operations
- Insertion: O(log n) on average
- Deletion: O(log n) on average
- Search: O(log n) on average

## Traversals
- In-order: Left, Root, Right
- Pre-order: Root, Left, Right
- Post-order: Left, Right, Root
